A `class Name(Script)` in `game/main.py` is translated to Java by the build (never run). Fields are annotated (`speed: float = 200.0`) and can be set where the script is used (`Ship(speed=240.0)`). Methods: `on_start(self)`, `update(self, dt: float)`, `on_collide(self, other: Entity, side: str)`, `on_tap(self)`, `on_destroy(self)`, and your own (annotated).

Types: `Animator`, `Bar`, `Billboard`, `Body`, `Button`, `Canvas`, `Entity`, `GridController`, `Image`, `Keyboard`, `Panel`, `Prefab`, `Props`, `ScrollList`, `Shape`, `Slider`, `Sound`, `Sprite`, `Tabs`, `Text`, `Toggle`, `bool`, `float`, `int`, `str`, `void`, and the game's own `@dataclass` classes.

Python built-ins: `len`, `abs`, `min`, `max`, `round`, `int`, `float`, `str`, `range`, `print`; lists (`append`, `pop`, `insert`, `remove`, `clear`, `[i]`, `[-1]`, `len`), dicts with `str` keys (`[k]`, `get`, `keys`, `values`, `pop`, `clear`, `in`, `for k in d`, in insertion order), f-strings, `math` and `random` (seeded: the same game every run).

### Many files

Every `.py` file under `game/` is a module: `from game.x.y import name` or `import game.x.y as y`. A module holds imports, constants, module state (`STATE = Store()`: a list, a dict or a data class, reset for each new game and part of the state hash), plain functions, `@dataclass` classes and `Script` classes; the declarations stay in `game/main.py`. From `dataclasses`: `dataclass`, `field(default_factory=...)` and `replace(obj, field=value)`. Plain functions and data class methods can use `math` and `random`, not `game`, `scene`, `input` or `audio`.

### Data, JSON and saves

- `SPECIES = table("data/species", Species)` at the top of a module: the rows of `data/species.json` (a list) or `data/species/*.json` (a row per file), checked at build time against the `@dataclass` (which needs `id: str`). `SPECIES.get(id)`, `SPECIES.has(id)`, `SPECIES.all()`, `len(SPECIES)`, `for s in SPECIES`, `id in SPECIES`. A field `Ref[Move]` (or `list[Ref[Move]]`...) holds ids of the Move table, checked too. Treat rows as read-only.
- `to_json(value)` and `from_json(text, Type)`: a `@dataclass` (with lists, dicts and other data classes inside) to JSON text and back, the same text as CPython's `json.dumps(..., separators=(",", ":"))`. Unknown keys are ignored; missing ones take the default.
- `saves.write(slot, text)`, `saves.read(slot)` (`None` when empty), `saves.exists(slot)`, `saves.delete(slot)`, in Script methods. Writes are atomic; a read is recorded in the journal, so a game brought back plays with the text it read.
- Tiled: an object's custom properties are `self.props.get_str(key)` / `get_int` / `get_float` / `get_bool` / `has`; a tile's custom properties are `scene.tile_tag(x, y, key)` ("" when no tile there has it; hidden layers count).
