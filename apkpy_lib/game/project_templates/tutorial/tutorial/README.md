# Tutorial: a red square that follows your finger

This is the smallest game you can make with ApkPy: a white screen and a red square. Press the screen and the square moves to your finger. That is all of it.

The whole game is 6 lines, in one file: [`game/main.py`](../game/main.py).

Do the steps in order. Each one takes a couple of minutes, and you see the result at the end of each.

| Step | What you do |
|---|---|
| [1. Before you start](01-before-you-start.md) | Check that your computer is ready |
| [2. Make the project](02-make-the-project.md) | Create the folder and the two files the app needs |
| [3. A white screen](03-white-screen.md) | Your first game: an empty white screen |
| [4. A red square](04-red-square.md) | Put something on the screen |
| [5. Follow the finger](05-follow-the-finger.md) | Make it move |
| [6. On your phone](06-on-your-phone.md) | Play it for real, and get an APK |
| [7. Try changing things](07-try-changing-things.md) | Small changes that teach you the rest |

This folder already holds the finished game. You can run it right now with `apkpy game play`, and compare your work with it at any time.
