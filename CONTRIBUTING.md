# Contributing to ApkPy

First of all, thank you for taking the time to contribute! 🎉

ApkPy is a **closed-source** project, so we do not accept pull requests to the core codebase. However, there are many valuable ways you can contribute to the community:

---

## 🐛 Reporting Bugs

If you find a bug, please [open an issue](../../issues/new?template=bug_report.md) and include:

- **ApkPy version** (run `pip show apkpy`)
- **Python version** (run `python --version`)
- **Operating System** (Windows / macOS / Linux)
- A **minimal code snippet** that reproduces the bug
- The **full error message** or unexpected output

The more detail you provide, the faster we can fix it.

---

## 💡 Requesting Features

Have an idea for a new component, CSS property, or workflow improvement?

[Open a feature request](../../issues/new?template=feature_request.md) and describe:

- **What you want to do** that you currently can't
- **Why it would be useful** to other developers
- Any **examples or references** from other frameworks

---

## 📝 Contributing Examples

We love seeing what the community builds! You can contribute to the public [`examples/`](examples/) folder by opening an issue with your example code and a short description. If it's clean and demonstrates something useful, we'll add it.

---

## 💬 Community Guidelines

- Be respectful and inclusive.
- Stay on topic — this repository is specifically for ApkPy.
- Search existing issues before opening a new one.

---

Thank you for helping make ApkPy better! 🚀
